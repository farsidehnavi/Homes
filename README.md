# سامانه جامع تحلیل و جستجوی فایل اکسل املاک نجف‌آباد (Real Estate Excel Viewer & Analyzer)

یک وب‌اپلیکیشن مدرن، سریع و واکنش‌گرا (Responsive) با **React 19** ، **TypeScript** و **Tailwind CSS** جهت بارگذاری، مشاهده، جستجوی پیشرفته، فیلترینگ و تحلیل داده‌های فایل اکسل املاک به همراه ۱۰۰ ملک استخراج شده از فایل نجف‌آباد.

---

## 🚀 ویژگی‌های کلیدی

- **بارگذاری انواع فایل‌های اکسل و CSV**: پشتیبانی از Drag & Drop و انتخاب فایل با پسوندهای `.xlsx`، `.xls` و `.csv`.
- **پیش‌بارگذاری با ۱۰۰ رکورد واقعی**: شامل تمامی ستون‌ها (آدرس، نوع ملک، متراژ، تعداد اتاق، طبقه، سن بنا، جهت، نما، پارکینگ، آسانسور، انباری، نوع سند و قیمت).
- **محاسبه هوشمند قیمت هر متر مربع**: استخراج و محاسبه خودکار قیمت هر متر و فرمت‌بندی خوانا (میلیارد و میلیون تومان).
- **فیلترهای پیشرفته چندگانه**:
  - جستجوی متنی در تمامی ستون‌ها با نرمال‌سازی حروف فارسی (ی/ي، ک/ك)
  - فیلتر بر اساس بازه قیمت (کل و هر متر مربع)
  - فیلتر بازه متراژ و تعداد اتاق
  - فیلتر امکانات رفاهی (پارکینگ، آسانسور، انباری)
  - فیلتر نوع سند، سن بنا، جهت جغرافیایی و نمای ساختمان
- **دو نمای مجزا**:
  - **نمای جدولی (Table View)**: با مرتب‌سازی صعودی/نزولی ستون‌ها
  - **نمای کارتی (Cards View)**: بهینه‌سازی شده برای گوشی موبایل و تبلت
- **خروجی اکسل**: امکان دانلود اکسل نمونه و دانلود رکوردهای فیلتر شده.
- **تغییر فرمت اعداد**: سوییچ بین ارقام فارسی (۱۲۳) و انگلیسی (123).

## 🛠️ نحوه نصب و اجرای محلی (Local Setup)

### پیش‌نیازها
- **Node.js** نسخه 18 یا بالاتر
- **npm** یا **yarn** یا **bun**

### مراحل اجرا:

1. وارد پوشه پروژه شوید:
```bash
cd project-directory
```

2. پکیج‌ها و وابستگی‌ها را نصب کنید:
```bash
npm install
```

3. سرور توسعه را اجرا کنید:
```bash
npm run dev
```

4. مرورگر خود را باز کرده و آدرس زیر را مشاهده کنید:
```
http://localhost:3000
```

## 📦 دستورات اسکریپت (Scripts)

- `npm run dev`: اجرای برنامه در حالت توسعه
- `npm run build`: بیلد بهینه برای استقرار تولید (Production)
- `npm run preview`: پیش‌نمایش نسخه بیلد شده
- `npm run lint`: بررسی خطاهای TypeScript
